# Phase 3B + Phase 3C

## Phase 3B — Offers CMS
- Add, edit and delete offers
- Direct JPG, PNG and WebP image upload
- Discount label and coupon code
- Internal or external call-to-action link
- Start and end scheduling
- Featured and public controls
- Sort order
- Homepage offer cards
- Public `/offers` page
- Expired and future offers automatically hidden

## Phase 3C — Reviews CMS
- Add, edit and delete reviews
- Optional customer/review image upload
- 1–5 star rating
- Customer display name and city
- Product or service
- Verified-customer, featured and published controls
- Review date and sort order
- Homepage review cards
- Public `/reviews` page
- Draft reviews hidden from the public

## Security
- Admin-only write policies
- Public read policies only for active offers and published reviews
- Public storage buckets restricted to supported image formats and 5 MB
- Images are uploaded directly; no image URL field is exposed in the CMS
